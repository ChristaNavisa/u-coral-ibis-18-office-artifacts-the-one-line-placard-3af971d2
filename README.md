A one-line museum placard for an ordinary office object, written as if it were an ancient artifact dug from a lost civilisation — entry for [Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2).

> Lanyard, c. 2019. Woven neck-chain of the Badge Bearers, worn to open every door in the temple. It opened none.

## Run

```sh
node main.ts
```

Writes the placard to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program refuses to write an entry outside the 1–180 character gate.
